ESP32 Mensaje Web

Un sistema IoT mínimo y completo: una página web edita un mensaje, un backend FastAPI en Docker lo guarda y una ESP32 lo consulta por WiFi y lo muestra en el Monitor Serie.

Empezar (Getting Started) → Ver la arquitectura Código en GitHub

Este proyecto es un ejemplo de clase de Máquinas Digitales (Unillanos, 2026-2). Está pensado para que, partiendo de un computador recién instalado con Windows o Linux, puedas montar todo el sistema, entender cada pieza y luego extenderlo.

flowchart LR
    U["👤 Usuario"] -->|escribe mensaje| W["🌐 Frontend<br/>nginx :3000"]
    W -->|PUT /mensaje| B["⚙️ Backend<br/>FastAPI :8000"]
    E["📟 ESP32"] -->|GET /mensaje/texto<br/>cada 1 s| B
    E -->|USB Serial| S["🖥️ Monitor Serie"]

Figura 1. El sistema completo en una línea.

¿Qué vas a aprender?

  • Preparar un workspace de desarrollo embebido + web (Git, Docker, Arduino IDE, drivers USB-Serial).
  • Levantar servicios con Docker Compose (backend Python y servidor web nginx).
  • Diseñar una API REST sencilla con FastAPI y consumirla desde un navegador y desde un microcontrolador.
  • Conectar una ESP32 a WiFi y hacer peticiones HTTP con HTTPClient.
  • Distinguir la vista física (cables, radio, placas) de la vista lógica (IPs, puertos, protocolos).
  • Diagnosticar fallos típicos: puerto COM, firewall, IP equivocada, red de 5 GHz…

Estructura del repositorio

.
├── docker-compose.yml          # Levanta backend (8000) y frontend (3000)
├── backend/
│   ├── Dockerfile              # Imagen python:3.12-slim + uvicorn
│   ├── main.py                 # API FastAPI (mensaje en memoria)
│   └── requirements.txt
├── frontend/
│   ├── index.html              # Formulario para editar el mensaje
│   ├── app.js                  # Llama a la API en http://<host>:8000
│   └── styles.css
├── esp32/
│   └── esp32_mensaje/
│       ├── esp32_mensaje.ino   # Sketch de Arduino
│       ├── config.example.h    # Plantilla de configuración (se sube)
│       └── config.h            # Tu WiFi e IP reales (NO se sube)
└── docs/                       # Esta documentación (GitHub Pages)
🔒 Credenciales

Las credenciales WiFi nunca se suben al repositorio. Viven en esp32/esp32_mensaje/config.h, que está en .gitignore. En el repo solo está la plantilla config.example.h.
