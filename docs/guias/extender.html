Extender el proyecto

Ideas y código para pasar de “imprimir un mensaje” a un sistema IoT útil. Cada sección es independiente.

Controlar el LED de la placa

Haz que la ESP32 actúe según el mensaje: ON enciende el LED azul (GPIO2 en la mayoría de DevKit) y OFF lo apaga.

const int LED_PIN = 2;   // LED integrado en muchas placas DevKit

void setup() {
  pinMode(LED_PIN, OUTPUT);
  // ... resto igual ...
}

void aplicarMensaje(const String& m) {
  String cmd = m;
  cmd.trim();
  cmd.toUpperCase();
  if (cmd == "ON")       digitalWrite(LED_PIN, HIGH);
  else if (cmd == "OFF") digitalWrite(LED_PIN, LOW);
}

// dentro de loop(), cuando llega un mensaje nuevo:
if (mensaje != ultimoMensaje) {
  Serial.print("Nuevo mensaje: ");
  Serial.println(mensaje);
  aplicarMensaje(mensaje);
  ultimoMensaje = mensaje;
}

Escribe on en la web y el LED se enciende en ≤ 1 s. Con un LED externo, conéctalo a GPIO 4 con una resistencia de 220–330 Ω a GND y cambia LED_PIN.

Reto

Soporta BLINK 500 para parpadear cada 500 ms. Necesitarás la técnica de la siguiente sección.

Temporizar sin delay

delay(1000) congela el programa. Con millis() (milisegundos desde el arranque) puedes consultar el servidor cada segundo y hacer otras cosas entre medias:

const unsigned long PERIODO_MS = 1000;
unsigned long ultimaConsulta = 0;

void loop() {
  unsigned long ahora = millis();
  if (ahora - ultimaConsulta >= PERIODO_MS) {
    ultimaConsulta = ahora;
    consultarBackend();      // el código HTTP que antes estaba en loop()
  }
  leerBotones();             // se ejecuta miles de veces por segundo
  actualizarParpadeo();
}

La resta ahora - ultimaConsulta con unsigned long funciona incluso cuando millis() se desborda (cada ~49 días).

Mostrar el mensaje en una pantalla

Una LCD 16×2 con módulo I²C (PCF8574) o una OLED SSD1306 se conectan a SDA = GPIO 21 y SCL = GPIO 22. Instala la librería desde Tools → Manage Libraries (p. ej. LiquidCrystal I2C o Adafruit SSD1306) y llama a lcd.print(mensaje) cuando cambie.

Voltaje

Muchas LCD 16×2 son de 5 V. Aliméntalas desde VIN y verifica que el módulo I²C no suba las líneas SDA/SCL a 5 V (o usa un conversor de nivel).

Persistir el mensaje

Hoy el mensaje se pierde al reiniciar el contenedor. Guardarlo en un archivo JSON dentro de un volumen lo hace sobrevivir:

import json
from pathlib import Path

DATA = Path("/data/mensaje.json")


def cargar() -> str:
    try:
        return json.loads(DATA.read_text(encoding="utf-8"))["mensaje"]
    except (FileNotFoundError, KeyError, json.JSONDecodeError):
        return "Hola mundo"


def guardar(valor: str) -> None:
    DATA.parent.mkdir(parents=True, exist_ok=True)
    DATA.write_text(json.dumps({"mensaje": valor}, ensure_ascii=False), encoding="utf-8")


mensaje: str = cargar()

# ... en actualizar_mensaje():
#     mensaje = datos.mensaje
#     guardar(mensaje)
  backend:
    build: ./backend
    volumes:
      - ./data:/data

Añade data/ al .gitignore. Para más datos (historial, varios dispositivos) el siguiente paso es SQLite.

Validar y limitar el mensaje

from pydantic import BaseModel, Field

class Mensaje(BaseModel):
    mensaje: str = Field(min_length=1, max_length=64)

FastAPI responderá 422 a mensajes vacíos o de más de 64 caracteres, útil si el destino es una pantalla de 16 columnas.

Proteger el PUT con un token

import os
from fastapi import Header, HTTPException

TOKEN = os.getenv("API_TOKEN", "cambiame")

@app.put("/mensaje")
def actualizar_mensaje(datos: Mensaje, x_token: str = Header(default="")):
    if x_token != TOKEN:
        raise HTTPException(status_code=401, detail="Token inválido")

El frontend debe enviar la cabecera X-Token. Define el valor con environment: - API_TOKEN=... en Compose (y no lo subas al repo).

Reportar estado desde la ESP32

Invierte la dirección: añade POST /estado en el backend y haz que la ESP32 envíe su IP, intensidad de señal y temperatura:

HTTPClient http;
http.begin(String("http://") + BACKEND_HOST + ":" + BACKEND_PORT + "/estado");
http.addHeader("Content-Type", "application/json");
String body = String("{\"ip\":\"") + WiFi.localIP().toString() +
              "\",\"rssi\":" + WiFi.RSSI() + "}";
int code = http.POST(body);
http.end();

Muestra esos datos en la web: ya tienes un panel de monitoreo.

Más ejercicios

  • Varias ESP32, cada una con su propio mensaje: /dispositivos/{id}/mensaje.
  • Historial de mensajes con fecha y hora.
  • Portal de configuración WiFi en la ESP32 (librería WiFiManager) para no recompilar al cambiar de red.
  • Guardar BACKEND_HOST en la memoria no volátil con Preferences.h.
  • Descubrir el backend automáticamente con mDNS (ESPmDNS.h) en lugar de usar una IP fija.
  • Actualizaciones de firmware por WiFi (OTA, ArduinoOTA.h).
