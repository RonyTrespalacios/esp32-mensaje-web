Publicar esta documentación

Este sitio es HTML estático dentro de la carpeta docs/. GitHub Pages puede servirlo directamente, sin compilación.

Activar GitHub Pages

Desde la web de GitHub

  1. Abre el repositorio en GitHub → Settings → Pages (menú izquierdo).
  2. Source: Deploy from a branch.
  3. Branch: main y carpeta /docs → Save.
  4. Espera 1–2 minutos. La URL aparece arriba en la misma página: https://<usuario>.github.io/<repositorio>/.

Desde la terminal (GitHub CLI)

gh api -X POST repos/<usuario>/<repositorio>/pages \
  -f "source[branch]=main" -f "source[path]=/docs"

Cada git push a main que modifique docs/ vuelve a publicar el sitio automáticamente. El progreso se ve en la pestaña Actions (pages build and deployment).

Ver el sitio en local

Los diagramas y el resaltado se cargan como módulos desde CDN, así que conviene servir la carpeta por HTTP en lugar de abrir el archivo con doble clic:

cd docs
python -m http.server 8080
# o, sin Python, con Docker:
docker run --rm -p 8080:80 -v ${PWD}:/usr/share/nginx/html:ro nginx:alpine
cd docs
python3 -m http.server 8080
# o con Docker:
docker run --rm -p 8080:80 -v "$PWD":/usr/share/nginx/html:ro nginx:alpine

Abre http://localhost:8080.

Cada página contiene solo su contenido dentro de <article class="doc">. docs.js genera alrededor el encabezado, el panel izquierdo (a partir de la constante NAV), la tabla “En esta página”, las migas de pan y los botones Anterior/Siguiente.

Agregar una página

  1. Copia una página existente de la misma carpeta, p. ej. guias/extender.html → guias/mi-guia.html.
  2. Ajusta el <body>: data-page="guias/mi-guia.html" (ruta relativa a docs/) y data-root="../" ("" si está en la raíz).
  3. Escribe el contenido con <h1>, <h2> y <h3>. Los h2 aparecen como subsecciones en el panel izquierdo.
  4. Regístrala en NAV dentro de assets/js/docs.js: 
    { t: "Mi guía", p: "guias/mi-guia.html", k: "palabras clave para la búsqueda" },
