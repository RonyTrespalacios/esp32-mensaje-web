4. Clonar y levantar servicios

Descargarás el código con Git y levantarás el backend y el frontend con un solo comando de Docker Compose.

Clonar el repositorio

cd $HOME\workspace
git clone https://github.com/RonyTrespalacios/esp32-mensaje-web.git
cd esp32-mensaje-web
cd ~/workspace
git clone https://github.com/RonyTrespalacios/esp32-mensaje-web.git
cd esp32-mensaje-web

git clone crea la carpeta esp32-mensaje-web con todo el historial. A partir de ahora, todos los comandos se ejecutan desde esa carpeta.

¿Hiciste un fork?

Si vas a modificar el proyecto y subir tus cambios, primero haz Fork en GitHub y clona tu copia: https://github.com/<tu-usuario>/esp32-mensaje-web.git.

Levantar con Docker Compose

Asegúrate de que Docker está corriendo (en Windows, Docker Desktop abierto) y ejecuta:

docker compose up -d --build
Parte del comandoSignificado
docker composeLee docker-compose.yml de la carpeta actual.
upCrea y arranca los servicios backend y frontend.
-dDetached: corre en segundo plano y te devuelve la terminal.
--buildConstruye (o reconstruye) la imagen del backend a partir de backend/Dockerfile.

La primera vez tarda uno o dos minutos: descarga python:3.12-slim y nginx:alpine e instala FastAPI. Las siguientes veces es casi instantáneo.

Qué ocurre por dentro

sequenceDiagram
    participant T as Terminal
    participant C as Docker Compose
    participant R as Docker Hub
    participant BE as Contenedor backend
    participant FE as Contenedor frontend
    T->>C: docker compose up -d --build
    C->>R: descarga python:3.12-slim y nginx:alpine
    C->>C: build backend/Dockerfile (pip install)
    C->>BE: arranca uvicorn en :8000
    C->>FE: arranca nginx en :80 (publicado como :3000)
    C-->>T: Container mensaje-backend Started / mensaje-frontend Started

Verificar que está funcionando

docker compose ps

Debes ver dos contenedores con estado running (o Up):

NAME               IMAGE                    SERVICE    STATUS         PORTS
mensaje-backend    esp32-mensaje-web-backend backend   Up 10 seconds  0.0.0.0:8000->8000/tcp
mensaje-frontend   nginx:alpine             frontend   Up 10 seconds  0.0.0.0:3000->80/tcp

Ahora abre en el navegador:

URLQué debes ver
http://localhost:3000La página Mensaje para la ESP32 mostrando “Hola mundo”.
http://localhost:8000/mensaje{"mensaje":"Hola mundo"}
http://localhost:8000/mensaje/textoHola mundo (texto plano, lo que lee la ESP32)
http://localhost:8000/docsSwagger UI: documentación interactiva de la API.
Prueba rápida

Escribe un mensaje en localhost:3000 y pulsa Guardar. Luego recarga localhost:8000/mensaje/texto: debe mostrar tu mensaje. ¡El backend funciona!

Comandos del día a día

ComandoPara qué
docker compose psVer el estado de los servicios.
docker compose logs -f backendVer en vivo las peticiones que llegan al backend (incluidas las de la ESP32). Ctrl+C para salir.
docker compose restart backendReiniciar el backend (el mensaje vuelve a “Hola mundo”).
docker compose up -d --buildAplicar cambios hechos en backend/main.py.
docker compose downDetener y eliminar los contenedores.
¿Y los cambios del frontend?

La carpeta frontend/ está montada como volumen dentro de nginx, así que basta con guardar el archivo y recargar el navegador (Ctrl+F5). No hace falta reconstruir.
