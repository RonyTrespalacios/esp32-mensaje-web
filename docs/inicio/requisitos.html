1. Requisitos

Antes de instalar nada, verifica que tienes el hardware y conoces el software que vamos a usar. Esta página es una lista de verificación.

Hardware

ElementoDetalleObligatorio
ComputadorWindows 10/11 (64 bits) o Linux (Ubuntu 22.04/24.04 o similar). 8 GB de RAM recomendados para Docker. Con adaptador WiFi.Sí
Placa ESP32Cualquier ESP32 DevKit (ESP32-WROOM-32, NodeMCU-32S, etc.).Sí
Cable USBDebe ser de datos (no solo de carga). Micro-USB o USB-C según la placa.Sí
Red WiFi 2.4 GHzPuede ser el hotspot del propio computador o un router. La ESP32 no soporta 5 GHz.Sí
CelularPara probar la web desde otro dispositivo.Opcional
Cómo saber si tu cable es de datos

Conecta la placa: si Windows hace el sonido de “dispositivo conectado” o en Linux aparece un nuevo /dev/ttyUSB0 o /dev/ttyACM0, el cable transmite datos. Si solo se enciende el LED de la placa y nada más, probablemente es un cable de carga.
