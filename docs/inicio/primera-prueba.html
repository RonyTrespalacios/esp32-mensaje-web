8. Prueba de extremo a extremo

Con todo en marcha, comprobarás que un mensaje escrito en el navegador llega a la ESP32 en aproximadamente un segundo.

Lista previa

✔CondiciónCómo comprobarla
☐Contenedores corriendodocker compose ps → dos servicios Up
☐ESP32 conectada al WiFiMonitor Serie muestra Conectado. IP ESP32: …
☐ESP32 llega al backendMonitor Serie muestra Nuevo mensaje: Hola mundo

La prueba

  1. Abre los logs del backend en una terminal: 
    docker compose logs -f backend
    Verás una línea por segundo: es la ESP32 preguntando. 
    mensaje-backend  | INFO:  192.168.137.23:51234 - "GET /mensaje/texto HTTP/1.1" 200 OK
  2. Abre la web en http://localhost:3000 (o desde el celular: http://<IP-del-PC>:3000).
  3. Escribe un mensaje, por ejemplo Encender LED, y pulsa Guardar. La web muestra Mensaje actualizado ✔ y en los logs aparece un PUT /mensaje.
  4. Mira el Monitor Serie. En ≤ 1 segundo aparece: 
    Nuevo mensaje: Encender LED
sequenceDiagram
    actor U as Tú
    participant W as Web :3000
    participant B as Backend :8000
    participant E as ESP32
    U->>W: escribe "Encender LED" + Guardar
    W->>B: PUT /mensaje
    B-->>W: 200 {"mensaje":"Encender LED"}
    Note over E,B: como máximo 1 s después
    E->>B: GET /mensaje/texto
    B-->>E: 200 Encender LED
    E->>E: Serial.println("Nuevo mensaje: ...")

Pruebas adicionales

Desde la línea de comandos

Invoke-RestMethod -Method Put -Uri http://localhost:8000/mensaje `
  -ContentType "application/json" -Body '{"mensaje":"Hola desde PowerShell"}'
curl -X PUT http://localhost:8000/mensaje \
  -H "Content-Type: application/json" -d '{"mensaje":"Hola desde curl"}'

Resiliencia

  • Apaga el backend (docker compose stop backend): la ESP32 imprime Error HTTP: -1 cada segundo. Vuelve a encenderlo (docker compose start backend) y se recupera sola; el mensaje vuelve a Hola mundo porque se guarda en memoria.
  • Apaga el hotspot: la ESP32 imprime WiFi desconectado, reconectando... y se reconecta al volver la red.
  • Dos navegadores a la vez: cambia el mensaje en uno y observa cómo el otro se actualiza solo en ≤ 2 s.
