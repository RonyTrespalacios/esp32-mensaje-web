5. Arduino IDE y placa ESP32

Instalarás Arduino IDE 2, el driver USB-Serial de tu placa y el soporte de placas ESP32 de Espressif. La placa de referencia del curso es la DOIT ESP32 DEVKIT V1.

Sobre las ilustraciones

Las imágenes de esta página son recreaciones de las ventanas reales, con el lugar donde debes hacer clic marcado con un número rojo. Según tu versión de Windows o de Arduino IDE, las ventanas pueden verse un poco distintas.

Instalar Arduino IDE 2

winget install --id ArduinoSA.IDE.stable -e

Alternativa: descarga el instalador Windows Win 10 and newer, 64 bits en arduino.cc/en/software. Si el asistente pregunta si quieres instalar controladores USB, acepta.

Descarga el AppImage (Linux AppImage 64 bits) desde arduino.cc/en/software y ejecútalo:

mkdir -p ~/Applications
mv ~/Descargas/arduino-ide_*_Linux_64bit.AppImage ~/Applications/
chmod +x ~/Applications/arduino-ide_*_Linux_64bit.AppImage
~/Applications/arduino-ide_*_Linux_64bit.AppImage

Si no abre, revisa que instalaste libfuse2 o libfuse2t64 (paso 3). Alternativa: flatpak install flathub cc.arduino.IDE2.

Identificar el chip USB-Serial

En la mayoría de placas, el ESP32 no se conecta por USB directamente: hay un chip puente USB ↔ UART junto al conector. En la DOIT ESP32 DEVKIT V1 suele ser un CH340 o un CP2102. Míralo con lupa o con la cámara del celular:

Texto en el chipFabricanteDriver
CH340, CH340C, CH341, CH9102WCH (Nanjing Qinheng)CH341SER
CP2102, CP2104, SILABSSilicon LabsCP210x VCP

Instalar el driver

CH340 / CH341 (el más común)

DescargaContenido
Directa (zip): kio4.com/arduino/imagenes/ch341ser_win.zipCH341SER.EXE, versión de 2017 (190 KB). Es una copia que publica el tutorial de kio4.com y funciona en Windows 10/11.
Oficial del fabricante: wch-ic.com/downloads/CH341SER_EXE.htmlVersión más reciente. Pulsa el botón Download de la página.
  1. Descomprime el zip (clic derecho → Extraer todo).
  2. Ejecuta CH341SER.EXE (clic derecho → Ejecutar como administrador).
  3. Pulsa INSTALL y espera el mensaje Driver install success!

CP2102 / CP210x

  1. Descarga CP210x Universal Windows Driver desde silabs.com/developers/usb-to-uart-bridge-vcp-drivers.
  2. Descomprime el ZIP, haz clic derecho en silabser.inf → Instalar.

Comprobar el puerto COM

Conecta la placa con el cable USB y abre el Administrador de dispositivos (Win+X → Administrador de dispositivos). Expande Puertos (COM y LPT) y anota el número COM.

Si en lugar de eso aparece Otros dispositivos → USB2.0-Serial con un triángulo amarillo, el driver no está instalado. Si no aparece nada, prueba otro cable: puede ser uno de solo carga.

También puedes listar los puertos desde PowerShell:

Get-CimInstance Win32_SerialPort | Select-Object DeviceID, Description

Los drivers ch341 y cp210x ya vienen en el kernel: no hay que instalar nada. Solo verifica el grupo dialout y el problema de brltty explicados en el paso 3.

Conecta la placa y comprueba:

sudo dmesg | tail -n 5          # debe mencionar ch341-uart o cp210x
ls -l /dev/ttyUSB* /dev/ttyACM*  # p. ej. /dev/ttyUSB0, grupo dialout

Agregar las placas de Espressif

Arduino IDE no trae de fábrica las placas ESP32. Para agregarlas se le indica una URL donde Espressif publica la lista de paquetes.

URL del gestor de placas

URLVersiones del core que ofreceCuándo usarla
https://espressif.github.io/arduino-esp32/package_esp32_index.jsonTodas, hasta la más reciente (3.x)Recomendada. Es la URL oficial actual de Espressif.
https://dl.espressif.com/dl/package_esp32_index.jsonSolo hasta la 1.0.6 (2021)La URL antigua, la que usan muchos tutoriales, entre ellos el de kio4. Funciona y el proyecto compila con ella, pero instala un core viejo.
  1. Abre las preferencias. File → Preferences (en español: Archivo → Preferencias). Atajo: Ctrl+,.
  2. Pega la URL en el campo Additional boards manager URLs (Gestor de URLs Adicionales de Tarjetas). Si ya tienes otras URLs, sepáralas con una coma. 
    https://espressif.github.io/arduino-esp32/package_esp32_index.json
  3. Pulsa OK. El IDE descarga el índice; puede tardar unos segundos.

Instalar el paquete esp32

  1. Abre el gestor de placas. Tools → Board → Boards Manager… o el segundo ícono de la barra lateral izquierda.
  2. Busca esp32.
  3. Instala “esp32 by Espressif Systems”. No confundir con Arduino ESP32 Boards, que es otro paquete. La descarga ocupa unos 300 MB entre compilador y herramientas.
¿Qué instala ese paquete?
  • El compilador cruzado xtensa-esp32-elf-gcc, que convierte el C++ en instrucciones del procesador Xtensa del ESP32.
  • El framework ESP-IDF precompilado, con la capa Arduino encima.
  • Librerías como WiFi.h, HTTPClient.h, WebServer.h y Preferences.h.
  • esptool, la herramienta que escribe el binario en la memoria flash por el puerto serie.
  • Las definiciones de las placas, entre ellas DOIT ESP32 DEVKIT V1.

Seleccionar placa y puerto

  1. Placa: Tools → Board → esp32 → DOIT ESP32 DEVKIT V1. Si tu placa es otra, ESP32 Dev Module sirve para casi cualquier DevKit con ESP32-WROOM-32.
  2. Puerto: Tools → Port → COMx en Windows (el de la figura 2) o /dev/ttyUSB0 en Linux.

También puedes usar el selector de la barra superior del IDE (Select Board), que agrupa placa y puerto en un solo menú.

Prueba de humo (opcional)

Antes de cargar el proyecto, comprueba que todo funciona con un ejemplo mínimo: File → Examples → 01.Basics → Blink, cambia LED_BUILTIN por 2 (el LED azul de la DOIT DEVKIT V1 está en el GPIO2) y pulsa Upload. Si el LED parpadea, el compilador, el driver y el puerto están bien.
