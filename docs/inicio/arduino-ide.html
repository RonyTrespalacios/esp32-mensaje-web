5. Arduino IDE y placa ESP32

Instalarás Arduino IDE 2, el driver USB-Serial de tu placa y el soporte de placas ESP32 de Espressif.

Instalar Arduino IDE 2

winget install --id ArduinoSA.IDE.stable -e

Alternativa: descarga el instalador Windows Win 10 and newer, 64 bits en arduino.cc/en/software. Durante la instalación, acepta instalar los controladores USB que ofrece el asistente.

Descarga el AppImage (Linux AppImage 64 bits) desde arduino.cc/en/software y ejecútalo:

mkdir -p ~/Applications
mv ~/Descargas/arduino-ide_*_Linux_64bit.AppImage ~/Applications/
chmod +x ~/Applications/arduino-ide_*_Linux_64bit.AppImage
~/Applications/arduino-ide_*_Linux_64bit.AppImage

Si no abre, revisa que instalaste libfuse2 / libfuse2t64 (paso 3). Alternativa: flatpak install flathub cc.arduino.IDE2.

Identificar el chip USB-Serial

El ESP32 no habla USB directamente (en la mayoría de DevKits): la placa tiene un chip puente USB ↔ UART junto al conector. Míralo con atención (puede requerir lupa o la cámara del celular):

Texto en el chipFabricanteDriver
CH340, CH340C, CH341, CH9102WCH (Nanjing Qinheng)CH341SER
CP2102, CP2104, SILABSSilicon LabsCP210x VCP
Sin chip aparte (ESP32-S3/C3 con USB nativo)EspressifNo necesita driver

Instalar el driver

CH340 / CH341 / CH9102

  1. Descarga CH341SER.EXE desde wch-ic.com/downloads/CH341SER_EXE.html.
  2. Ejecútalo como administrador y pulsa INSTALL. Debe decir Driver install success!

CP2102 / CP210x

  1. Descarga CP210x Universal Windows Driver desde silabs.com/developers/usb-to-uart-bridge-vcp-drivers.
  2. Descomprime el ZIP, clic derecho en silabser.inf → Instalar.

Comprobar

Conecta la placa y abre el Administrador de dispositivos (Win+X → Administrador de dispositivos) → Puertos (COM y LPT). Debe aparecer algo como USB-SERIAL CH340 (COM5) o Silicon Labs CP210x USB to UART Bridge (COM4). Anota el número COM.

Desde PowerShell también puedes listarlos:

Get-CimInstance Win32_SerialPort | Select-Object DeviceID, Description

Los drivers ch341 y cp210x vienen incluidos en el kernel: no hay que instalar nada. Solo verifica los permisos (dialout) y el problema de brltty del paso 3.

Conecta la placa y comprueba:

sudo dmesg | tail -n 5          # debe mencionar ch341-uart o cp210x
ls -l /dev/ttyUSB* /dev/ttyACM*  # p. ej. /dev/ttyUSB0, grupo dialout

Agregar las placas de Espressif

Arduino IDE no trae soporte para ESP32 de fábrica. Se agrega mediante un índice de paquetes publicado por Espressif.

  1. Abre las preferencias. File → Preferences (en español: Archivo → Preferencias). Atajo: Ctrl+,.
  2. Pega la URL en el campo Additional boards manager URLs (si ya hay otras, sepáralas con coma): 
    https://espressif.github.io/arduino-esp32/package_esp32_index.json
  3. Pulsa OK. El IDE descargará el índice.
  4. Abre el gestor de placas. Tools → Board → Boards Manager… o el segundo ícono de la barra lateral izquierda.
  5. Instala “esp32 by Espressif Systems”. Escribe esp32 en el buscador y pulsa Install en ese paquete (no en “Arduino ESP32 Boards”). Descarga ~300 MB entre compilador y herramientas; ten paciencia.
¿Qué instala ese paquete?
  • El compilador cruzado xtensa-esp32-elf-gcc (convierte C++ en instrucciones del procesador Xtensa del ESP32).
  • El framework ESP-IDF precompilado y la capa Arduino encima.
  • Librerías como WiFi.h, HTTPClient.h, WebServer.h, Preferences.h.
  • esptool, la herramienta que escribe el binario en la memoria flash por el puerto serie.

Seleccionar placa y puerto

  1. Placa: Tools → Board → esp32 → ESP32 Dev Module (sirve para casi todos los DevKit con ESP32-WROOM-32). Si tu placa tiene otro nombre en la lista, elígelo.
  2. Puerto: Tools → Port → COMx (Windows) o /dev/ttyUSB0 (Linux).

Prueba de humo (opcional)

Antes de cargar el proyecto, verifica la cadena completa con un ejemplo mínimo: File → Examples → 01.Basics → Blink, cambia LED_BUILTIN por 2 si no compila, y pulsa Upload. Si el LED azul de la placa parpadea, compilador, driver y puerto están bien.
