7. Programar la ESP32

Compilarás el sketch, lo cargarás en la placa y leerás lo que imprime por el Monitor Serie.

Abrir el sketch

  1. File → Open… y selecciona esp32/esp32_mensaje/esp32_mensaje.ino.
  2. Revisa las pestañas. Arduino IDE abre todos los archivos de la carpeta del sketch: verás esp32_mensaje.ino, config.example.h y config.h. Si config.h no aparece, vuelve al paso 6.
Regla de Arduino

El archivo .ino debe estar dentro de una carpeta con el mismo nombre (esp32_mensaje/esp32_mensaje.ino). Por eso no conviene renombrar uno sin el otro.

Compilar (Verify)

Pulsa el botón ✓ Verify (Ctrl+R). La primera compilación tarda 1–3 minutos porque compila el núcleo completo del ESP32. Al final verás algo como:

Sketch uses 912345 bytes (69%) of program storage space. Maximum is 1310720 bytes.
Global variables use 44768 bytes (13%) of dynamic memory, leaving 282912 bytes for local variables.

Cargar (Upload)

  1. Verifica placa y puerto en la barra superior: ESP32 Dev Module en COMx o /dev/ttyUSB0.
  2. Pulsa → Upload (Ctrl+U).
  3. Observa la consola. Aparecerá Connecting.... y luego Writing at 0x00010000... (10 %) hasta Hard resetting via RTS pin....
Se queda en “Connecting.....”

Algunas placas no entran solas en modo de programación. Mantén presionado el botón BOOT (o IO0) cuando veas Connecting... y suéltalo al empezar Writing at…. Si persiste, baja Tools → Upload Speed a 115200.

¿Qué hace la carga por dentro?

flowchart LR
    A["esp32_mensaje.ino<br/>+ config.h"] -->|xtensa-esp32-elf-gcc| B["esp32_mensaje.ino.bin"]
    B -->|esptool por USB-Serial| C["Chip CH340 / CP2102"]
    C -->|UART0 TX/RX| D["Bootloader ROM del ESP32"]
    D -->|escribe| E["Memoria flash 4 MB"]
    E -->|reset| F["Tu programa corre"]

Monitor Serie

  1. Ábrelo: Tools → Serial Monitor (Ctrl+Shift+M).
  2. Velocidad: 115200 baud (selector en la esquina derecha). Debe coincidir con Serial.begin(115200).
  3. Pulsa EN / RST en la placa para reiniciarla y ver el arranque desde el principio.
