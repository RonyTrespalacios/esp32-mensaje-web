2. Workspace en Windows

Prepararás un Windows 10/11 recién instalado con todo lo necesario: gestor de paquetes, Git, WSL 2, Docker Desktop y (opcional) VS Code.

¿Usas Linux?

Salta a 3. Workspace en Linux.

Abrir PowerShell

Todos los comandos de esta página se ejecutan en PowerShell: botón Inicio → escribe PowerShell → Enter. Cuando se indique como administrador, haz clic derecho → Ejecutar como administrador.

Verificar winget

winget es el gestor de paquetes oficial de Windows. Viene incluido en Windows 11 y en Windows 10 actualizado.

winget --version

Si el comando no existe, instala “Instalador de aplicación” (App Installer) desde Microsoft Store y vuelve a abrir PowerShell.

Instalar Git

winget install --id Git.Git -e

Alternativa manual: git-scm.com/download/win (acepta las opciones por defecto). Cierra y vuelve a abrir PowerShell para que se actualice el PATH, y verifica:

git --version

Configurar tu identidad

Git firma cada commit con un nombre y un correo. Configúralo una sola vez:

git config --global user.name "Tu Nombre"
git config --global user.email "tu.correo@unillanos.edu.co"

Instalar WSL 2

Docker Desktop en Windows ejecuta los contenedores Linux dentro de WSL 2 (Windows Subsystem for Linux). En PowerShell como administrador:

wsl --install

Reinicia el equipo cuando termine. Si ya estaba instalado, actualízalo con wsl --update.

Virtualización

WSL 2 y Docker necesitan la virtualización por hardware activa. Compruébalo en Administrador de tareas → Rendimiento → CPU → Virtualización: Habilitado. Si dice Deshabilitado, actívala en la BIOS/UEFI (Intel VT-x, AMD-V o “SVM Mode”).

Instalar Docker Desktop

winget install --id Docker.DockerDesktop -e

Alternativa: docker.com/products/docker-desktop.

  1. Abre Docker Desktop desde el menú Inicio.
  2. Acepta los términos. Puedes omitir el inicio de sesión (Skip).
  3. Espera a que el motor arranque. El indicador inferior debe decir Engine running.

Verifica desde PowerShell:

docker --version
docker compose version
docker run --rm hello-world

El último comando descarga una imagen de prueba y debe imprimir Hello from Docker!.

Docker al iniciar Windows

Los comandos docker solo funcionan con Docker Desktop abierto. En Settings → General puedes activar Start Docker Desktop when you sign in.

(Opcional) Instalar VS Code

winget install --id Microsoft.VisualStudioCode -e

Extensiones útiles: Python, Docker y C/C++ (para leer el sketch con resaltado; la carga a la placa se hace con Arduino IDE).

Crear la carpeta de trabajo

Usa una ruta sin espacios ni tildes para evitar problemas con las herramientas de compilación:

mkdir $HOME\workspace
cd $HOME\workspace
