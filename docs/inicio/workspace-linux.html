Instrucciones para Ubuntu 22.04 / 24.04 y derivadas (Linux Mint, Pop!_OS…). En otras distribuciones cambia apt por tu gestor de paquetes.

git --version

Instalar Docker Engine y Compose

En Linux no necesitas Docker Desktop: basta con Docker Engine y el plugin Compose. La forma más rápida es el script oficial:

curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

Para usar docker sin sudo, agrega tu usuario al grupo docker:

sudo usermod -aG docker $USER

Cierra sesión y vuelve a entrar para que el cambio de grupo surta efecto. Verifica:

docker --version
docker compose version
docker run --rm hello-world
Instalación desde el repositorio APT

Si prefieres no usar el script, sigue la guía oficial: docs.docker.com/engine/install/ubuntu.

Permisos para el puerto serie

En Linux la ESP32 aparece como /dev/ttyUSB0 (chip CH340/CP210x) o /dev/ttyACM0 (USB nativo). Esos dispositivos pertenecen al grupo dialout; tu usuario debe pertenecer a él para cargar firmware:

sudo usermod -aG dialout $USER

Cierra sesión (o reinicia) y comprueba con groups que aparezcan docker y dialout.

Ubuntu 22.04+ y el chip CH340: brltty

El servicio brltty (para líneas braille) se apropia de los adaptadores CH340 y el puerto desaparece segundos después de conectar la placa. Si no usas un lector braille, elimínalo:

sudo apt remove -y brltty

Dependencias de Arduino IDE (AppImage)

Arduino IDE 2 para Linux se distribuye como AppImage, que necesita la librería FUSE 2:

sudo apt install -y libfuse2t64
sudo apt install -y libfuse2

La instalación del IDE en sí está en el paso 5.

(Opcional) VS Code

sudo snap install code --classic

Crear la carpeta de trabajo
