Glosario

Términos usados a lo largo de la documentación, en orden alfabético.

TérminoDefinición
API RESTInterfaz que expone recursos (aquí, /mensaje) manipulables con métodos HTTP estándar (GET, PUT…).
ASGIInterfaz estándar entre servidores web asíncronos de Python (uvicorn) y frameworks (FastAPI).
Baudios (baud)Símbolos por segundo en una línea serie. A 115200 baud se transmiten ~11 520 bytes/s.
BootloaderPrograma en ROM del ESP32 que, al arrancar con GPIO0 en bajo, recibe un nuevo firmware por el puerto serie.
CH340 / CP2102Chips puente USB ↔ UART usados en placas de desarrollo.
ContenedorProceso aislado con su propio sistema de archivos, creado a partir de una imagen de Docker.
CORSCross-Origin Resource Sharing: mecanismo por el que un servidor autoriza a páginas de otro origen a leer sus respuestas.
DHCPProtocolo que asigna automáticamente IP a los dispositivos que se unen a una red.
Docker ComposeHerramienta para definir y ejecutar varios contenedores con un archivo YAML.
EndpointCombinación de método + ruta que atiende la API, p. ej. GET /mensaje/texto.
esptoolHerramienta de Espressif que escribe firmware en la flash del ESP32.
FirmwarePrograma que se ejecuta en el microcontrolador (el sketch compilado).
FlashMemoria no volátil donde se guarda el firmware.
GPIOGeneral Purpose Input/Output: pin digital configurable como entrada o salida.
HotspotPunto de acceso WiFi creado por un computador o celular.
IdempotenteOperación que produce el mismo resultado se ejecute una o varias veces (como PUT).
Imagen (Docker)Plantilla inmutable con sistema de archivos y metadatos para crear contenedores.
JSONFormato de texto para datos estructurados: {"mensaje":"Hola"}.
localhostNombre que apunta al propio dispositivo (127.0.0.1).
MiddlewareCódigo que se ejecuta antes/después de cada petición (p. ej. CORS).
Monitor SerieVentana de Arduino IDE que muestra lo que la placa envía con Serial.print.
MQTTProtocolo ligero de publicación/suscripción muy usado en IoT.
nginxServidor web que aquí entrega los archivos del frontend.
OrigenCombinación de esquema + host + puerto (http://localhost:3000).
PollingConsultar periódicamente si algo cambió, en lugar de recibir avisos.
Puerto (TCP)Número (0–65535) que identifica un servicio dentro de una IP: 8000 backend, 3000 frontend.
PydanticLibrería de validación de datos basada en anotaciones de tipo de Python.
SketchPrograma de Arduino (.ino + archivos de su carpeta).
SoCSystem on Chip: CPU, memoria y periféricos en un solo chip.
SSIDNombre de una red WiFi.
SubredConjunto de IPs que se comunican directamente, p. ej. 192.168.137.0/24.
UARTPeriférico de comunicación serie asíncrona (TX/RX).
uvicornServidor ASGI que ejecuta la aplicación FastAPI.
Volumen / bind mountCarpeta del host visible dentro de un contenedor.
WSL 2Subsistema de Windows para Linux; Docker Desktop lo usa para ejecutar contenedores.
