¿Qué es FastAPI?

FastAPI es un framework web para Python que convierte funciones normales en endpoints HTTP. Usa las anotaciones de tipo de Python para validar automáticamente los datos de entrada y generar documentación interactiva (/docs). No sirve peticiones por sí solo: lo ejecuta un servidor ASGI llamado uvicorn.

Código completo

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import PlainTextResponse
from pydantic import BaseModel

app = FastAPI(title="Mensaje API")

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

# Almacenamiento simple en memoria
mensaje: str = "Hola mundo"


class Mensaje(BaseModel):
    mensaje: str


@app.get("/mensaje")
def obtener_mensaje():
    """Devuelve el mensaje en JSON: {"mensaje": "..."}"""
    return {"mensaje": mensaje}


@app.get("/mensaje/texto", response_class=PlainTextResponse)
def obtener_mensaje_texto():
    """Devuelve el mensaje como texto plano (ideal para la ESP32)."""
    return mensaje


@app.put("/mensaje")
def actualizar_mensaje(datos: Mensaje):
    global mensaje
    mensaje = datos.mensaje
    return {"mensaje": mensaje}

Bloque por bloque

Importaciones

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import PlainTextResponse
from pydantic import BaseModel
  • FastAPI: la clase de la aplicación.
  • CORSMiddleware: permite que páginas servidas desde otro origen llamen a esta API (ver abajo).
  • PlainTextResponse: respuesta con Content-Type: text/plain en lugar de JSON.
  • BaseModel (de Pydantic): define la forma de los datos de entrada y los valida.

La aplicación

app = FastAPI(title="Mensaje API")

Crea el objeto app. El nombre importa: el Dockerfile arranca uvicorn main:app, es decir, “el objeto app del módulo main”. El title aparece en /docs.

CORS

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

El navegador aplica la política del mismo origen: una página cargada desde http://localhost:3000 no puede leer respuestas de http://localhost:8000 (otro puerto = otro origen) salvo que el servidor lo autorice con cabeceras Access-Control-Allow-*. Este middleware añade esas cabeceras.

sequenceDiagram
    participant B as Navegador (origen :3000)
    participant API as API :8000
    B->>API: OPTIONS /mensaje (preflight del PUT)
    API-->>B: Access-Control-Allow-Origin *, Allow-Methods *
    B->>API: PUT /mensaje
    API-->>B: 200 + Access-Control-Allow-Origin *
Solo para desarrollo

"*" permite a cualquier web llamar a la API. En producción se restringe, p. ej. allow_origins=["http://192.168.137.1:3000"]. La ESP32 no es un navegador, así que CORS no le afecta.

El estado

mensaje: str = "Hola mundo"

Una variable global del módulo. Vive en la RAM del proceso de uvicorn: se pierde al reiniciar el contenedor. La anotación : str es solo documentación (Python no la impone).

El modelo de entrada

class Mensaje(BaseModel):
    mensaje: str

Describe el cuerpo JSON que espera el PUT: un objeto con un campo mensaje de tipo texto. Si el cliente envía algo distinto (falta el campo, o envía un objeto), FastAPI responde automáticamente 422 Unprocessable Entity con el detalle del error, sin ejecutar tu función.

GET /mensaje

@app.get("/mensaje")
def obtener_mensaje():
    return {"mensaje": mensaje}

El decorador @app.get("/mensaje") registra la función para las peticiones GET a esa ruta. Devolver un dict hace que FastAPI lo serialice a JSON. El docstring aparece como descripción en /docs.

GET /mensaje/texto

@app.get("/mensaje/texto", response_class=PlainTextResponse)
def obtener_mensaje_texto():
    return mensaje

Igual que el anterior, pero con response_class=PlainTextResponse: la respuesta es el texto “crudo” (Hola mundo), no {"mensaje":"Hola mundo"}. Así la ESP32 puede usar http.getString() directamente sin parsear JSON.

PUT /mensaje

@app.put("/mensaje")
def actualizar_mensaje(datos: Mensaje):
    global mensaje
    mensaje = datos.mensaje
    return {"mensaje": mensaje}
  • Como el parámetro datos está anotado con un BaseModel, FastAPI sabe que debe leerlo del cuerpo de la petición, parsear el JSON y validarlo.
  • global mensaje es necesario porque se asigna la variable del módulo; sin él, Python crearía una variable local.
  • Se devuelve el nuevo valor para que el cliente confirme lo guardado.

Se usa PUT (y no POST) porque la operación reemplaza el recurso completo y es idempotente: enviarla dos veces deja el mismo estado.

Dependencias

fastapi==0.115.6
uvicorn[standard]==0.34.0

Las versiones están fijadas (==) para que la imagen se construya igual en cualquier máquina. [standard] instala extras de uvicorn como uvloop y httptools (más rendimiento) y soporte de WebSockets. Pydantic llega como dependencia de FastAPI.

Ejecutar sin Docker (opcional)

Útil para depurar con breakpoints. Requiere Python 3.10+.

cd backend
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000

--reload reinicia el servidor al guardar cambios. Detén antes el contenedor (docker compose stop backend) para liberar el puerto 8000.

Limitaciones conocidas

  • Sin persistencia: reiniciar = “Hola mundo”.
  • Sin autenticación: cualquiera en la red puede cambiar el mensaje.
  • Un solo proceso: si se ejecutara uvicorn con varios workers, cada uno tendría su propia copia de mensaje.
  • Sin límite de tamaño del texto.
